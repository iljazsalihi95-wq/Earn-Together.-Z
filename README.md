# We Earn Together
Private Android-native MVP. Neutral gaming identity; no religious imagery.

## Included
- Android Kotlin app with ten-question general-knowledge quiz
- 50/50 **illustrative simulation only**
- GitHub Actions debug APK workflow

## Not included
- Real advertisements, impression-level revenue, backend accounts, PayPal transfers
- No claim of earning real money. Before monetization, secure written approval from an advertising partner permitting cash-equivalent rewards.

## Build
Run GitHub Actions > Android APK or locally with Gradle 8.10.2 and JDK 17.
